# Input data and provenance

`sample_input/55.zip` contains four nested date ZIPs, each with nine Sentinel-2 Level-2A GeoTIFF band exports from Copernicus Browser. Study area: Al Raha Bay / Al Muneera Island, Abu Dhabi, UAE. Dates: 2023-03-29, 2023-04-03, 2023-04-06, 2023-04-28. Bands: B02, B03, B04, B05, B06, B07, B08, B8A, B11. Data source: Copernicus Data Space Ecosystem / Copernicus Browser (https://browser.dataspace.copernicus.eu/). Copernicus Sentinel data are provided on a free, full and open basis subject to applicable Copernicus legal notices and attribution requirements; check the current official terms at https://dataspace.copernicus.eu/. The code is separately MIT-licensed; this does not relicense satellite data.

Archive is provided for reproducing the PoC. `data/extracted/` is generated by the notebook and should not be committed. The ZIP is a previously exported sample; the original Copernicus scene IDs and exact export settings have not been independently verified and should not be invented.
